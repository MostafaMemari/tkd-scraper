# تک‌یار — سرویس اطلاعات هنرجویان

سرویس بک‌اند مبتنی بر **NestJS 11** برای سامانهٔ مدیریت هنرجویان باشگاه تکواندو (تک‌یار).

## معماری

پروژه با الگوی **Ports & Adapters** سازمان‌دهی شده تا لایهٔ کسب‌وکار کاملاً از پیاده‌سازی منبع داده جدا باشد:

```
src/
├── common/                  # ابزارهای عمومی (HTTP، Retry)
├── modules/
│   ├── student/             # API هنرجوها
│   │   ├── controller       # ورودی HTTP + اعتبارسنجی DTO
│   │   ├── service          # منطق کسب‌وکار
│   │   ├── ports/           # قرارداد (interface) — نقطهٔ تعویض پیاده‌سازی
│   │   ├── dto/             # اعتبارسنجی ورودی
│   │   └── types/           # مدل دامنه
│   └── guest/               # API نشست مهمان
└── infrastructure/          # پیاده‌سازی‌های واقعی پورت‌ها (adapter)
```

به این ترتیب، اگر منبع داده در آینده تغییر کند (مثلاً فایل رسمی اکسل فدراسیون یا API رسمی)،
فقط adapter لایهٔ `infrastructure` عوض می‌شود و بقیهٔ سامانه دست‌نخورده می‌ماند.

## راه‌اندازی

```bash
npm install
cp .env.example .env
npm run start:dev      # حالت توسعه (watch)
npm run build          # بیلد تولید
npm run start:prod     # اجرای نسخهٔ بیلد‌شده
```

## اندپوینت‌ها

| متد   | مسیر | توضیح |
|-------|------|-------|
| `GET` | `/api/students/by-national-code?nationalCode=...` | اطلاعات هنرجو بر اساس کد ملی (۸ تا ۱۰ رقم، فقط عدد) |
| `GET` | `/api/guest/session` | ایجاد نشست مهمان |

## نکتهٔ مهم و مسئولانه

ماژول اتصال به سامانهٔ membership فدراسیون (لایهٔ `infrastructure/tkd`) به مجوز رسمی و کتبی فدراسیون
نیازمند است. استفاده از این ماژول باید صرفاً در چارچوب مجوز صادرشده و با رعایت حریم خصوصی هنرجوها انجام شود.
